# FlowVoice

Hold Fn/Globe, speak, and release to insert your words at the cursor.

[Download FlowVoice v1.0.4 for Apple Silicon](https://github.com/harshith49/fn-voice/releases/download/v1.0.4/FlowVoice-v1.0.4-apple-silicon.dmg)

Requires macOS 14 or later. Drag FlowVoice into Applications, eject the DMG, and open the installed app. Enable Accessibility, Microphone, and Speech Recognition when asked. The current build requires Control-click → Open on first launch.

Voice-to-Prompt formats your speech into a prompt for Codex or another AI app. Formatting runs locally and requires no API key. Click the text field, hold Fn/Globe, speak, and release. Review the inserted prompt before submitting it.
